# Context Protocol Engine

A company-wide memory engine for **First Person** and **Canonic**. Indexes every active client engagement and Canonic's current sprint, kept in sync with Mission Control 2 by automation, driven from a Monday meeting workflow.

This repo is private and shared by the four founders (Tony, Drew, Marcello, Brandon).

## Spec

The full architecture spec is at [`docs/specs/cp-engine-spec-v01.md`](docs/specs/cp-engine-spec-v01.md). Read it before contributing.
